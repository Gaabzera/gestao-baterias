Marcone Baterias - Sistema de Gestão Operacional
Este é um sistema Full Stack desenvolvido para otimizar o fluxo de trabalho da Marcone Baterias. A plataforma permite o controle total de ordens de serviço (OS), rastreabilidade de garantias e gerenciamento visual de tarefas através de um quadro Kanban.

Funcionalidades Principais
Controle de Acesso: Tela de login para gerentes e mecânicos autorizados.

Quadro Kanban: Gerenciamento visual do status das ordens (A Fazer, Em Andamento, Concluído) com suporte a Drag and Drop (arrastar e soltar).

Calendário Dinâmico: Visualização de prazos e entregas integradas com o FullCalendar.

Gestão de OS: Cadastro completo de veículos, clientes, descrições técnicas e prazos.

Dashboard de Resumo: Indicadores rápidos de produtividade diária.

Rastreabilidade: Foco especial na garantia de baterias e lembretes de manutenção.
